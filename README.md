# RGB Color Mixing Experiment

## Overview
This project explores the RGB (Red, Green, Blue) color model through a computational experiment using Python.

It demonstrates how different colors are generated by mixing the three primary color channels: Red, Green, and Blue. The experiment also visualizes the RGB color space as a three-dimensional cube and examines its 2D cross-sections.

## Objectives
- Understand the RGB color model.
- Explore how RGB channels combine to produce different colors.
- Visualize the RGB color space as a 3D cube.
- Generate 2D cross-sections by fixing one color channel while varying the other two.
- Observe how changing RGB channel values affects the resulting colors.

## Experiment Description

### 1. RGB Cube
The RGB color space is represented as a three-dimensional cube, where each axis represents one color channel:
- **Red (R)**
- **Green (G)**
- **Blue (B)**

Each point inside the cube represents a specific color combination.

### 2. Cross-Section
A cross-section is generated by fixing the value of one RGB channel while allowing the other two channels to vary across their full range (0–255).

The experiment examines three cases:
- **Fixed Red (R = 127):** Green and Blue vary.
- **Fixed Green (G = 127):** Red and Blue vary.
- **Fixed Blue (B = 127):** Red and Green vary.

Each case produces a 2D visualization showing how two color channels combine while the third remains constant.
